D MD MUZAMMIL PORTFOLIO — CLICKABLE PROJECTS UPDATE

The existing homepage design and sections have been kept. The two project cards in the Projects section are now clickable.

Files:
- index.html: original portfolio homepage, with clickable project cards
- style.css: original styling plus small additions for the new orbit preview and clickable links
- profile.jpg: your supplied profile photo
- gym-id-card.html: standalone sample gym ID card project
- earth-sun.html: standalone minimalist Earth revolving around the Sun artwork
- project-pages.css: styling for the two standalone project pages

How to use:
1. Extract the ZIP.
2. Open the muzammil-portfolio folder in VS Code.
3. Right-click index.html and select Open with Live Server.
4. Scroll to Projects and click either project card.
5. Each project page has a link back to the portfolio.

The gym card is a sample design, not an official credential. The orbit is a simplified visual animation and not a scale-accurate astronomical model.
